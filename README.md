# Boutique de Rêve - l'art de l'Élégance Algérienne 🇩🇿

A responsive multi-page web application showcasing traditional Algerian fashion and garments, built to celebrate and preserve cultural heritage through modern web design.

## ✨ Features

- **Interactive Gallery & Showcases:** Detailed displays of traditional attire including Karako, Caftan, Blouza Oranaise, Ghelila, Robe Chaouia, and Robe Naili.
- **Dynamic User Experience:** Smooth navigation, elegant sliding hero sections, and immersive service grids.
- **Modern UI Animations:** Enhanced with interactive scroll animations (Scroll Reveal) to elevate the user journey.
- **Fully Responsive Design:** Optimized seamlessly for desktops, tablets, and mobile devices.

## 🛠️ Technologies Used

- **HTML5** & **CSS3** (Custom styling and layout design)
- **JavaScript** (Interactive components and animations)
- **GitHub Pages** (Hosting and deployment)
